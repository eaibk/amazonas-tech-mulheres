AMAZONAS TECH MULHERES
=====================

COMO ABRIR NO VS CODE
1. Extraia o arquivo ZIP.
2. Abra a pasta "amazonas-tech-mulheres" no Visual Studio Code.
3. Instale a extensão Live Server (opcional, mas recomendada).
4. Clique com o botão direito em index.html e escolha "Open with Live Server".

TELAS
- index.html: início
- quiz.html: apresentação do quiz
- pergunta.html: fluxo com 25 perguntas
- resultado.html: resultado vocacional calculado
- mulheres.html: mulheres que inspiram
- comunidades.html: busca e filtros de comunidades
- eventos.html: eventos e inscrição demonstrativa
- login.html: entrar
- cadastro.html: criar conta

FUNCIONALIDADES
- Cadastro e login demonstrativos usando localStorage do navegador.
- Acesso ao quiz protegido por login.
- 25 perguntas de perfil, sem respostas certas ou erradas.
- Pontuação por afinidade entre 7 áreas da tecnologia.
- Busca e filtros na página de comunidades.
- Links externos para inscrição nos eventos oficiais, liberados após login.
- Links para os canais oficiais de quatro comunidades reais de tecnologia de Manaus.

IMPORTANTE
Este é um protótipo front-end. Os dados de cadastro e senha ficam apenas no navegador
(localStorage), sem criptografia ou servidor. Não use senhas reais neste protótipo.
Para publicar com usuários reais, será necessário backend, banco de dados,
autenticação segura e integração de eventos. Os eventos e comunidades desta versão foram substituídos por iniciativas reais com links para páginas oficiais. Datas, vagas e condições podem mudar; confirme no site de cada organização.
As imagens recortadas das referências servem como ilustração e devem ser substituídas
por fotografias autorizadas e verificadas antes da publicação.
\n\nFLUXO DE LOGIN E QUIZ\nAo acessar o quiz sem estar autenticada, entre ou crie uma conta. Após login/cadastro, o sistema direciona automaticamente para pergunta.html (Pergunta 1 de 25). Usuárias já autenticadas que abrirem quiz.html também seguem diretamente para as perguntas.\n

COMO COLOCAR SUAS PRÓPRIAS FOTOS
1. Coloque os arquivos .jpg, .jpeg ou .png dentro da pasta assets. Prefira nomes simples, sem espaços ou acentos, por exemplo: evento-tech-connect.jpg.
2. No HTML, encontre a imagem que deseja trocar e altere o valor de src. Exemplo: <img src="assets/evento-tech-connect.jpg" alt="Mulheres participando de um encontro de tecnologia">.
3. Para trocar a logo, substitua o arquivo assets/logo.png mantendo esse nome, ou altere o caminho do src no cabeçalho de todas as páginas.
4. Para trocar as fotos das mulheres, edite o src das imagens em mulheres.html. Use retratos autorizados e mantenha o crédito da fotógrafa ou da fonte.
5. Para trocar as imagens dos eventos, edite os src com a classe event-photo em eventos.html.
6. Atualize a página com Ctrl + F5 para limpar o cache do navegador.

Dica: para fotos de perfil, use imagens quadradas; para eventos, prefira imagens horizontais. Se você me enviar as fotos que deseja usar, posso recortá-las e organizá-las na pasta assets sem alterar o restante do site.
